## 📌 Overview

This repository contains clean, well-documented Python scripts and markdown documentation covering:
- **String Methods** (`lower`, `upper`, `capitalize`, `title`, `strip`, `replace`, `split`, `find`, `count`, `startswith`, `endswith`, `isdigit`, `isalpha`, `join`)
- **List Methods** (`append`, `insert`, `remove`, `pop`, `sort`, `reverse`, `count`, `index`, `extend`, `clear`)
- **Tuple Methods** (`count`, `index`)
- **Set Methods** (`add`, `update`, `remove`, `discard`, `pop`, `clear`)
- **Dictionary Methods** (`keys`, `values`, `items`, `get`, `update`, `pop`, `popitem`, `copy`, `clear`)
- **File Handling** (`open`, `write`, `read`, `readline`, `readlines`, `close`, `tell`, `seek`)
- **JSON Methods** (`dumps`, `loads`, `dump`, `load`)
- **Key Python Differences & Comparisons** (e.g. `find()` vs `index()`, `append()` vs `extend()`, `remove()` vs `pop()`, `==` vs `is`, `sort()` vs `sorted()`, `isdigit()` vs `isnumeric()`, etc.)
